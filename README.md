# Fieldnotes · Web App

A calm personal knowledge studio, hosted with GitHub Pages.

Open https://jneildsouza.github.io/fieldnotes-web/ after the Pages deployment completes.

- Notebooks, reusable components and linked Markdown
- Private patch cards and separate presenter/audience views
- Azure, Glacier and Periwinkle themes with RGB accent controls
- Local browser storage, JSON backup/import and Markdown vault exports
- Recording controls with browser-selected screen and optional microphone

This repository contains only the app interface and sample content. Your personal notebooks and recordings stay in your browser and are never uploaded here. Each browser/device has its own workspace; use backup/import to transfer it. Export regularly before clearing browser data.

Use **Add component** to start and **Appearance** to change the palette.
